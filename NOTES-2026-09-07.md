## Traps already paid for — do not rediscover these

Each of these cost real time this session. All are *measured*, not assumed.

**`shadow.radius` is ignored by `PCFSoftShadowMap`.** It only applies to PCF and
VSM. The project carried `radius = 1.8` under PCFSoft for ages: paying the most
expensive filter Three offers for a blur setting that never ran.

**Cached shadow maps and wind-animated depth are incompatible.** Injecting wind
into `customDepthMaterial` while the map re-renders at ~12 Hz means every
refresh catches the leaves at a different point in the gust — the whole dapple
strobes. Reads as "jittery shadows"; no amount of filtering or resolution helps,
because the problem is temporal. Leaves now cast from rest pose.

**`material.onBeforeCompile` is a single slot, and assigning it silently
destroys whatever was there.** `wind.js` clobbered the pastel colour grade on
exactly the meshes that sway. It now chains, stashing the original on
`userData.__preWindCompile` so repeated calls (one material, many meshes) chain
the *same* original instead of wrapping the wrapper — which would duplicate the
injected GLSL into a redefinition error.

**`patch` is a reserved word in GLSL ES 3.0** (tessellation). Naming a variable
that failed the whole ground shader to compile, which silently dropped the
entire ground plane — the "washed out ground" was the sky dome showing below the
horizon. **Always assert zero failed programs after a shader change** (recipe
below); a failed program drops objects with no visible error.

**The material shader is in LINEAR HDR, not sRGB.** The scene renders through an
EffectComposer, so `<tonemapping_fragment>` and `<colorspace_fragment>` inside
the material are no-ops — `OutputPass` does both at the end. Values exceed 1, so
anything scaling by luminance blows out to white. Hue rotations that preserve
luminance are exposure-independent and safe.

**`InstancedMesh.count` is a draw range, not an allocation.** Free to lower at
runtime — no realloc, no matrix re-upload. This is why the adaptive quality
system can thin grass and scatter on the fly. `material.side` is *not* safe to
change at runtime: it sets `needsUpdate` and recompiles ~14 canopy materials, a
multi-hundred-ms freeze arriving exactly when the device is already struggling.

**`renderer.setPixelRatio()` must be followed by `composer.setSize()`.**
`EffectComposer.setSize` re-reads the pixel ratio; without it the render targets
stay at the old resolution and the change does nothing.

**`mergeStaticByMaterial` builds a NEW mesh that is visible by default.** It used
to fold invisible children in, silently resurrecting them. Now skips
`!child.visible`. If you hide something in the pond, check it stays hidden.

**`InstancedMesh` is culled against its GEOMETRY's bounding sphere** — which
describes one clump at the origin, not the scattered field. Must be widened by
hand or the whole field pops out when the origin clump leaves frame.

**`setColorAt` / `USE_INSTANCING_COLOR` measured as broken on this build.** The
define never reached the compiled shader despite a valid, populated
`instanceColor`. Per-instance colour goes through our own `aGrassColor`
attribute end to end. Don't "simplify" it back.

**Photogrammetry atlas alpha is chart padding, not a silhouette.** The pond's
`Material.006` texture is RGBA with ~16.5% near-zero alpha. Alpha-testing it
shattered the rocks into shards. But the *same material* also covers flat
vegetation cards whose alpha genuinely is their shape — forcing it opaque turned
those into black rectangles. Split into two shared variants keyed on **geometry**
(`Icosphere.*` solid vs `Plane.*` card), never on the material's `alphaMode`.

**`scene.environment` is a PMREM of `RoomEnvironment` — a room with rectangular
emissive light panels.** Any near-mirror surface (low roughness + high
`envMapIntensity`) will reflect one back as a hard white rectangle. That was the
pond's "ghost reflection"; it was never in the source asset.

**`KHR_materials_pbrSpecularGlossiness` is unsupported by GLTFLoader.** Models
using it load untextured (all `baseColorTexture` null). Fix with
`gltf-transform metalrough` *before* the rest of the pipeline. The banyan needed
this.

**Console messages in the browser pane go stale across navigations**, and a
console `await import('/src/x.js')` gets a **second module instance** — a
phantom with its own state. Read live singletons off `window.__gulmohar`,
`window.__quality`, `window.__wind` instead.

**`const` TDZ in animate() — sunWarmth used before declaration.** Had `sunWarmth`
declared at line 1421 but referenced at line 1350 inside the same function body.
JS `const` is block-scoped but its TDZ (temporal dead zone) covers the whole
scope from function entry, so the reference threw `ReferenceError: Cannot access
'sunWarmth' before initialization` on *every frame*. Fix: move `isMorning`,
`sunWarmth`, `targetSunColor`, `targetLightColor` to immediately after
`skySystem.update()` so all later code can use them freely.

**Pond `cascadeMat` was reconstructed per child instead of shared.** Each
waterfall mesh (Plane.120, Plane.121) got its own `onBeforeCompile` closure,
doubling shader compilation and producing two independent uniform sets. One
`if (!cascadeMat)` guard makes a single material shared across all cascade planes
correctly.

## Where things live

- `src/quality.js` — tier definitions, GPU probe, adaptive loop. `QUALITY` is a
  mutated-in-place singleton, so importers can hold the reference.
- `groundHeightAt()` in `src/scene/garden.js` — **the single source of ground
  height**. The ground mesh, the path, grass, fallen leaves and micro-plants all
  read it. Miss one and it floats. Also carries `pondShapeAt()`, the irregular
  pond outline shared by bed, bank and water so they agree exactly.
- `scripts/extract-cards.py` — pulls unique meshes out of assets that ship one
  card duplicated hundreds of times. Caveat: it copies **whole bufferViews**, so
  on an asset that interleaves many meshes into shared views the output balloons
  (17.7 MB once). Re-encoding through `gltf-transform meshopt` compacts it.

## Asset pipeline

Documented in `README.md`. Order matters:
`metalrough` (only if spec-gloss) → `resize` → `simplify` → `weld` → `dedup` →
`prune` → `meshopt`. Never run `join` — `setupPond` and `setupFloorEverywhere`
identify sub-meshes by node name, and joining destroys those names. (This is
exactly how the pond's `plane.002` apron check went dead: the name check was
correct, but processing had stripped the name from the shipped GLB.)

## Verification recipes

Dev server on **5183** (`.claude/launch.json`). Paste into the console.

**Shader link check — run after every shader change:**
```js
const a = window.__gulmohar, gl = a.renderer.getContext();
a.renderer.compile(a.scene, a.camera);
a.renderer.info.programs.filter(p => p.program &&
  !gl.getProgramParameter(p.program, gl.LINK_STATUS)).length   // must be 0
```

**Force a tier:** `?q=low` / `?q=med` / `?q=high`. `?edit` pins high and
disables adaptation.

**Frame timing is unreliable in the Browser pane** (rAF is throttled;
`gl.finish()` does not force a real sync there). `renderer.info` triangle and
draw-call counts *are* exact. Judge real frame time in a normal window.

## Session changes — 2026-09-08

### Lighting & sky

- **Smooth diurnal sky transitions** (`src/sky/celestial.js`): replaced abrupt
  night-mix step with continuous 3-way `smoothstep` blend between day, twilight
  and night. Milky Way fade shifted from `-0.12` to `-0.28` sun altitude for
  more realistic nautical/astronomical twilight.

- **Crimson sunset/sunrise sun and light colours** (`main.js`): `C_SUN_LOW`
  → `0xd81202`, `C_SUN_DAWN` → `0xeb2406`, `C_SUNLIGHT_LOW` → `0xff3600`,
  `C_SUNLIGHT_DAWN` → `0xff4c14`. Horizon and sky palette tuned to match.

- **Softer shadows** (`main.js`): `sunLight.shadow.intensity` reduced to
  `sunShadow * 0.62` (was `sunShadow * 1.0`); `moonLight.shadow.intensity`
  reduced to `moonShadow * 0.45` (was `0.70`). Ambient lift:
  `ambientLight.intensity = 0.12·night + 0.22·twi + 0.16·day` (was
  `0.03/0.08/0.02`). Hemisphere lift: `0.42·night + 0.65·twi + 0.58·day`
  (was `0.28/0.50/0.40`). Tone-mapping exposure raised from `1.08` → `1.15`.

- **Hemisphere and ground bounce colours lifted** (`main.js`):
  `C_HEMI_NIGHT` → `0x38486e`, `C_HEMI_GROUND_NIGHT` → `0x283244`,
  `C_HEMI_GROUND_DAY` → `0x6a7d54`, `C_FLOOR_MIDNIGHT` → `0x28382c`.
  Removes crushed blacks from shadowed areas at night.

### Pond diurnal lighting (`src/scene/garden.js`)

- Surface water material gains full diurnal uniforms: `uDayWeight`,
  `uTwiWeight`, `uNightWeight`, `uSkyColor`, `uHorizColor`, `uSunDir`,
  `uSunColor`, `uSunIntensity`, `uMoonDir`, `uMoonColor`, `uMoonIntensity`.
- Fresnel now reflects actual sky/horizon colour (not hardcoded blue).
- Specular glint uses sun vs moon direction/colour depending on time of day.
- Water base colour lerps between `C_WATER_DAY` (emerald), `C_WATER_DUSK`
  (bronze-amber), `C_WATER_DAWN` (rosy amber), `C_WATER_NIGHT` (indigo).
- Cascade waterfall material shares one instance (was reconstructed per mesh)
  and darkens to near-black at night with moonlit foam tint.
- `pond.update()` now accepts a `lightCtx` object passed through
  `garden.update(time, delta, lightCtx)`.

### Banyan tree

- Scaled 1.5× (`height: 17.5` → `26.25` in `BACKGROUND_TREES`).
- Ground-clear exclusion radius updated from `6.8` → `10.2` m to prevent
  grass and scatter spawning inside the larger root spread.

### Path / Gazebo gap

- Closed the visual gap between the gazebo floor and pathway surface by
  adjusting path-radius bulge and entrance apron width in `pathRadiusAt`.

## What is still open

From the approved plan (`~/.claude/plans/joyful-moseying-fern.md`), phases 1–3
are done. Remaining, in the order the plan recommends:

1. **Phase 5 — progressive loading.** Biggest *perceived* win. All models load
   in one `Promise.all`; `onProgress` is never wired (the hook already exists,
   unused, in `loadGarden`'s `loadGLTF`), and an unconditional 12s backstop can
   reveal a garden with no trees. Use per-file byte progress, not
   LoadingManager item counts — those jump in steps and can run backwards.
2. **Phase 6 — usability / a11y / SEO.** No keyboard nav beyond the Escape key
   added this session; the dock auto-hides after 6s and focus never resets that
   timer, so a keyboard user tabs into an invisible dock. No
   `prefers-reduced-motion` anywhere. No WebGL-failure fallback. No OG tags,
   robots.txt or sitemap. `work/index.html` and `public/paintings.json` describe
   the same artwork with contradicting dimensions and neither reads the other.
3. **Phase 4 — KTX2/Basis.** Largest memory win: ~98 MB of texture VRAM → very
   roughly 20 MB, and smaller downloads. `KTX2Loader` and the Basis transcoder
   are already in `node_modules`, just unwired; the transcoder needs copying
   into `public/`. Payload is now ~54 MB of models, so this is the lever for
   load time.
4. **Phase 7 — realism.** Gated to high tier and cheapest-first. Note the scene
   is **fill-bound**, so a full-screen AO pass is the wrong first move.

Smaller loose ends: `about/` is four placeholder blocks, `work/index.html` ships
build instructions as body copy, `SITE.email` is empty, and `createFlowerBeds()`
is defined but never called.
